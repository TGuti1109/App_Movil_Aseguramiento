NOTA: Se concertó con el fabricante del software el desarrollo de una aplicación denominada APPSIISMED, la cual integrará todas las aplicaciones móviles del SIISMED en un único punto de acceso. En la fase 1, la aplicación incluirá la APP de PAIMED y, en la fase 2, incorporará la APP de Aseguramiento. Descripción HU
Esta funcionalidad permitirá consultar y visualizar la lista de indicadores configurados desde el módulo de indicadores para este módulo APASE, ofreciendo filtros y criterios de búsqueda.

El objetivo es permitir a los usuarios acceder fácilmente a los indicadores existentes, conocer su definición, históricos de valores calculado, fecha de actualización, periodicidad y módulo de origen.

Además, el sistema debe garantizar que solo se muestren los indicadores configurados para el módulo y que el acceso a la información se controle de acuerdo con los roles y permisos definidos para cada tipo de usuario. 
Roles Como
Usuario con rol de administrador.
Usuario con rol de visualización
Usuario operativo
Característica / Funcionalidad. 
El sistema debe permitir al usuario:

Visualizar la lista de indicadores existentes para el módulo
Permitir utilizar filtros mediante criterios como: Nombre o código del indicador, Fecha de última actualización, Estado (activo/inactivo), Periodicidad (mensual, trimestral, anual), Responsable o área.
Buscar indicadores específicos mediante un campo de búsqueda por texto libre.
Visualizar información detallada de la Ficha del indicador seleccionado, 
Visualizar la tendencia histórica de un indicador, si existen versiones o periodos calculados.
Razón /Resultado. 
Facilitar la consulta centralizada y organizada de los indicadores del módulo, optimizando la experiencia de uso y reduciendo tiempos de búsqueda.
Tomar decisiones informadas basadas en los indicadores disponibles.
